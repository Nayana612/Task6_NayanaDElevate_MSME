# **🌸 Iris Species Classification with KNN**
This project uses the famous Iris dataset to classify flower species based on their features. We apply the K-Nearest Neighbors (KNN) algorithm and visualize how it separates different classes
using scatter plots and decision boundaries.

### **📂 Dataset**
**Source: IRIS.csv**

**Features:**

* sepal_length

* sepal_width

* petal_length

* petal_width

**Target: species (Setosa, Versicolor, Virginica)**

### **🧠 Model**
**Algorithm: K-Nearest Neighbors (KNN)**

**K-value: 3**

**Purpose: Classify iris flowers into 3 species based on sepal and petal measurements.**

### **📊 Visualizations**
2D scatter plots to observe feature separation.

Optional decision boundary visualization using matplotlib.


### **✅ Requirements**
* Python 3.x

* Pandas

* Numpy

* Matplotlib

* Seaborn

* Scikit-learn
